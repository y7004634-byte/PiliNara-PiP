PiliNara iOS native PiP + zh-TW
================================

Target
- PiliNara 2.1.3
- Starfallan/media-kit native branch
- iOS 15+ native system Picture-in-Picture
- iPhone 16 supported

Expected behavior
- Enable Background Picture-in-Picture in PiliNara playback settings.
- Start a video, then press Home or switch apps.
- The video continues in iOS system PiP.
- PiP play/pause controls are forwarded to media_kit.
- Returning to PiliNara restores in-app playback.
- Final IPA is post-patched to Traditional Chinese.
